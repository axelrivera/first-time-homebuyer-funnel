## Working pattern

When drafting each email:

1. Copy `C2-day-28-savings.md` as a template (same length, same voice, same single-CTA discipline).
2. Set `status: DRAFT`, fill in `subject`, `day`, `topic`, body.
3. Polish toward the two Hormozi tests: "Would they feel stupid to say no?" — for Tier C the answer is "no" because we're not asking for anything, but the analog is "would they feel stupid to delete this without reading?"
4. Lock as `POLISHED` once the rate/program/figure is current and verified.
